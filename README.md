## 💎 Ключевые Особенности

### 🗺️ Интерактивное Ядро (D3.js Mapping)
*   **Высокоточная векторная карта**: Отрисовка геоданных в реальном времени с поддержкой кастомных тем оформления.
*   **Smart Selection**: Система разблокировки регионов через модальные окна подтверждения.
*   **Dynamic Labels**: Интеллектуальный слой названий стран, следующий за курсором и поддерживающий мгновенную локализацию (RU/EN).

### 🎫 Экономическая Система "Boarding Pass"
*   **Валюта миль**: Внутренняя система накопления баллов для покупки эксклюзивных интерфейсов.
*   **Luxury UI**: Кошелек и элементы покупки стилизованы под реальные посадочные талоны (Boarding Passes) с динамической датой и номером рейса.

### 🖥️ Admin Terminal "Test.v.1.0"
*   **Hacker-Style Console**: Полнофункциональная панель управления в стиле ретро-футуризма.
*   **Force Control**: Мгновенная манипуляция балансом, принудительная разблокировка тем и полный сброс истории путешествий.
*   **Drag & Resize**: Полностью кастомизируемое окно консоли с поддержкой перетаскивания и изменения размера.

### 🛍️ Sector: Market
*   **Атмосферный магазин**: Стилизованная локация с персонажем-агентом, чей взгляд программно следует за курсором пользователя.
*   **Система лицензий**: Механика дешифровки и активации визуальных движков (Classic Luxury, Wooden и др.).

## 🏗️ Архитектура: Feature-Sliced Design (FSD)

Проект построен по методологии **FSD**, что обеспечивает идеальную изоляцию модулей и чистоту кода:

*   **App**: Глобальная инициализация, стили и конфигурация роутинга.
*   **Pages**: Высокоуровневые модули экранов (`MapPage`, `ShopPage`).
*   **Shared**: Переиспользуемый фундамент: утилиты рендеринга, конфиги тем и атомарные UI-компоненты.
*   **Stores**: "Мозговой центр" на базе Pinia, связывающий экономику и визуал через реактивные стейты.

## 📜 Основные правила этого проекта 

В проекте соблюдается строгий авторский Code Style:

1.  **No-Margin Policy**: Полный отказ от `margin`. Все отступы реализованы исключительно через `flex`, `gap` и `padding` для обеспечения монолитной адаптивности.
2.  **Multiline Hooks**: Для максимальной читаемости все хуки Vue и сложные функции оформляются в многострочном стиле.
3.  **Strict Typing**: Отказ от `any`. Все данные, включая D3-коллекции и свойства стран, строго типизированы через интерфейсы.
4.  **Utility-First**: Стилизация ведется только через атомарные классы Tailwind CSS.
